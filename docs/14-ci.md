# Continuous integration

The workflow file is not committed here because the current token cannot write to
`.github/workflows/`. Create `.github/workflows/ci.yml` in the GitHub UI with the contents
below, or push it from a local clone.

CI is CPU-only by design. The stub perception adapters mean the entire pipeline, including
the fall rules and the behaviour layer, is testable without a GPU or a camera. A test suite
that needs hardware is a test suite that stops being run.

```yaml
name: ci

on:
  push:
    branches: [main]
  pull_request:

jobs:
  python:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"
          cache: pip
      - name: Install
        run: |
          python -m pip install --upgrade pip
          pip install -e ".[dev]"
      - name: Lint
        run: ruff check src tests
      - name: Format check
        run: ruff format --check src tests
      - name: Type check
        run: mypy src
      - name: Test
        run: pytest -q

  sql:
    runs-on: ubuntu-latest
    services:
      postgres:
        image: postgres:16
        env:
          POSTGRES_PASSWORD: ci
          POSTGRES_DB: wellbeing
        options: >-
          --health-cmd pg_isready --health-interval 10s --health-timeout 5s --health-retries 5
        ports:
          - 5432:5432
    steps:
      - uses: actions/checkout@v4
      - name: Apply schema
        env:
          PGPASSWORD: ci
        run: |
          psql -h localhost -U postgres -d wellbeing -v ON_ERROR_STOP=1 -f sql/schema.sql
          psql -h localhost -U postgres -d wellbeing -v ON_ERROR_STOP=1 -f sql/retention.sql
```

## Gates that must stay in CI

| Gate | Why it is non-negotiable |
| --- | --- |
| `mypy src` strict | The contracts are the safety boundary; an untyped edge defeats them |
| Explanation completeness tests | An alert without all six fields must fail the build, not reach a caregiver |
| Fall hard-negative tests | Prevents a threshold change from quietly reintroducing false alarms |
| Baseline warmup tests | Prevents cold-start alert storms on a newly onboarded resident |
| `sql/schema.sql` apply | The `explanation_complete` and `evidence_present` constraints are load-bearing |
